Webhooks Documentation

What are Webhooks?

Webhooks allow third-party services to receive real-time notifications when events occur on the Creative Spark platform. When a supported event happens, we send an HTTP POST request to your configured endpoint with a JSON payload.

Supported Events

Security

Webhook requests include a signature header X-Signature that you can verify using your secret key. This ensures the request is genuinely from Creative Spark.

# Python verification
import hmac, hashlib
signature = request.headers['X-Signature']
expected = hmac.new(
  secret.encode(), 
  request.body, 
  hashlib.sha256
).hexdigest()
assert signature == expected
