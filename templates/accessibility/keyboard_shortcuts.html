Keyboard Shortcuts

Use these keyboard shortcuts to navigate Creative Spark more efficiently.

ShortcutAction
?Show this help dialog
g dGo to Dashboard
g iGo to Ideas List
cCreate new idea / item
/Focus search bar
nGo to Notifications
pGo to Profile
eEdit current item
DeleteDelete current item (with confirmation)
EscClose modal / cancel
tToggle dark mode
bToggle sidebar
Ctrl + EnterSubmit form / save
Ctrl + Shift + FFull-text search
Tips
  • Sequential shortcuts (like g then d) must be pressed within 1 second of each other.
  • You can customize these shortcuts in your accessibility settings.
  • Shortcuts are disabled when typing in input fields.
